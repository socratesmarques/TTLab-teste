# TTLab

O TTLab é uma plataforma de tênis de mesa. Use os comandos de build e teste do README. Ao modificar o catálogo e o modelo, confira a compatibilidade das configurações compartilhadas e salvas.

## Ferramentas de trabalho

- Use `frontend-design` ao criar interfaces e `web-design-guidelines` para revisar acessibilidade, responsividade e usabilidade.
- Use `webapp-testing` e Playwright MCP para verificar fluxos do TTLab no navegador. Para investigar console, rede ou desempenho, use Chrome DevTools MCP.
- Use Context7 para consultar documentação da versão de uma biblioteca usada pelo projeto. Se o serviço estiver indisponível, consulte a documentação oficial da biblioteca.
- Em sites de referência, use REA apenas quando a análise autorizada exigir evidências sobre o comportamento observável de funcionalidades públicas. Produza interface, marca, textos e recursos visuais próprios do TTLab.
- Mantenha configurações pessoais do Codex, credenciais, perfis de navegador e artefatos de teste fora dos commits. Reutilize ferramentas já disponíveis no ambiente. Consulte o [README](README.md) para registrar e validar as ferramentas.

## Fluxo de entrega

Trabalhe diretamente na branch `main`. Antes da edição, confira o remoto, preserve mudanças locais e integre o histórico existente por avanço rápido quando possível. Após cada etapa validada, faça commit e push normal para `origin main`. Respeite as proteções do repositório e informe eventuais bloqueios. Abra branches e PRs apenas se o usuário solicitar uma mudança de fluxo.
